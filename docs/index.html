Welcome to the Functional Programming group!

Research

We develop programming languages, methods and tools that make software more reliable, secure and usable. Members of the group have contributed to the design of Haskell, created property-based testing with QuickCheck, and built domain-specific languages for hardware design (Lava) and digital signal processing (Feldspar). Current work covers functional programming languages and their implementation, type systems, testing, hardware design and verification, and automated reasoning.

We also apply functional programming beyond software: multilingual language technology with Grammatical Framework, dependently typed models for mathematics and climate impact research (see DSLsofMath), reliable and efficient scientific computing, and usable artificial intelligence.
